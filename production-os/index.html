Reimagining India
Production OS

Reimagining India Production OS is a private media-production workflow supporting the creation, processing and management of production assets for the Reimagining India initiative.

Google Drive integration

The Production OS uses Google Drive authorization to work with production files made available to the application as part of its media-production workflow.

The application requests the Google Drive drive.file permission. This integration is used for production-file workflows and is not used for advertising or the sale of user data.

Private production system

The operational Production OS is not a public-facing service. Its infrastructure, administrative interfaces and production controls remain private and access-controlled.
